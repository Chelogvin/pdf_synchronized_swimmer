# 📄 PDF Translator

**Профессиональный переводчик PDF с вкладками, тремя переводчиками и ИИ-объяснениями.**

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Возможности

### 📑 Многодокументный режим
- Открытие нескольких PDF одновременно (вкладки как в браузере)
- Автоматическое восстановление открытых книг при запуске
- Быстрое переключение: `Ctrl+PageUp` / `Ctrl+PageDown`, `Ctrl+Tab`
- Закрытие вкладки: `Ctrl+W`

### 🌐 Три переводчика на выбор
| Переводчик | Бесплатно | Нужен ключ |
|-----------|-----------|------------|
| **Google Translate** | Да | Нет |
| **Яндекс.Переводчик** | 1 000 000 символов/мес | Да |
| **DeepL** | 500 000 символов/мес | Да (VPN) |

### 🤖 ИИ-объяснения
- Выделите фрагмент → нажмите **«Объяснить ИИ»**
- DeepSeek перескажет сложный текст своими словами

### 📖 Умная работа с PDF
- **Автоматическое сохранение абзацев** — текст переводится структурированно, а не «кашей»
- **Обрезка по Y** — исключает колонтитулы и номера страниц из перевода
- **Выделение фрагмента** — перевод по правому клику в плавающем окне
- **Синхронная прокрутка** — оригинал и перевод движутся вместе
- **Масштабирование** — `Ctrl+колесо` для PDF, `A+` / `A−` для текста перевода
- **Переход по номеру страницы** — быстрое перемещение по книге

### 🎨 Дизайн
- **Автоматическая тема** — светлая днём, тёмная ночью
- **Изумрудная палитра** — приятные глазу цвета
- **Современный интерфейс** — плоские кнопки, шрифт Segoe UI

### 🌍 Языки
- **На:** русский, английский, немецкий, французский, испанский, итальянский, китайский, японский
- **С:** автоопределение или конкретный язык

## 🚀 Установка

### 1. Установите Python
Скачайте с [python.org](https://www.python.org/downloads/) (3.10 или новее).

**Важно:** при установке поставьте галочку ✅ **«Add Python to PATH»**.

### 2. Установите зависимости

```bash
pip install PyMuPDF deep-translator Pillow requests sv-ttk
```

### 3. Запустите

```bash
python main.py
```

## 🔑 Настройка API

### Яндекс.Переводчик (рекомендуется для России)

1. Зарегистрируйтесь в [Яндекс.Облаке](https://console.yandex.cloud)
2. Создайте каталог (folder) → запомните **Folder ID**
3. Создайте сервисный аккаунт с ролью `ai.translate.user`
4. Создайте **API-ключ** в разделе «API-ключи»
5. В программе: **Перевод → Настройки API** → введите ключ и Folder ID

### DeepL

1. Зарегистрируйтесь на [deepl.com/pro-api](https://www.deepl.com/pro-api)
2. Получите бесплатный API-ключ
3. В программе: **Перевод → Настройки API** → введите ключ

### DeepSeek (для ИИ-объяснений)

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com)
2. Создайте API-ключ
3. В программе: **Перевод → Настройки API** → введите ключ

## ⌨️ Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl+O` | Открыть PDF |
| `Ctrl+T` | Новая вкладка |
| `Ctrl+W` | Закрыть вкладку |
| `Ctrl+PageUp/Down` | Предыдущая / следующая вкладка |
| `Ctrl+Tab` | Следующая вкладка |
| `←` `→` | Предыдущая / следующая страница |
| `PageUp` / `PageDown` | То же |
| `Ctrl+колесо` | Масштаб PDF |
| `Ctrl+±` | Размер шрифта перевода |
| **ПКМ по выделенному** | Перевод в плавающем окне |

## 📦 Сборка .exe

```bash
py -m PyInstaller --onefile --windowed --name="PDF_Translator" ^
  --hidden-import=fitz ^
  --hidden-import=deep_translator ^
  --hidden-import=PIL ^
  --hidden-import=requests ^
  --hidden-import=sv_ttk ^
  --icon="icon.ico" ^
  main.py
```

Готовый `.exe` появится в папке `dist/`.

## 🛠️ Технологии

- **Python 3.10+** — язык
- **tkinter** + **sv-ttk** — интерфейс
- **PyMuPDF (fitz)** — работа с PDF
- **deep-translator** — Google Translate
- **requests** — Яндекс, DeepL, DeepSeek API
- **Pillow** — отображение страниц
- **python-docx** — экспорт в Word (опционально)

---

## ⚠️ Важно

- **`settings.json` не должен попадать в Git** — он содержит API-ключи
- Для DeepL в России **нужен VPN**
- Google Translate может **блокировать IP** при частых запросах — используйте Яндекс
